# Technology Stack

## Frontend
- **HTML5** - Structure
- **CSS3** - Styling (via Bootstrap 4.4.1)
- **JavaScript (ES6+)** - Game logic (IIFE pattern)

## External Dependencies
- Bootstrap 4.4.1 (CDN) - UI framework
- underscore.js (local) - Array shuffling
- confetti (CDN) - Win celebration effect

## Development Tools
- No build process required
- Vanilla JavaScript (no framework)
- Single HTML file entry point

## Browser Support
- Modern browsers (Chrome, Firefox, Safari, Edge)
- Mobile responsive via Bootstrap
